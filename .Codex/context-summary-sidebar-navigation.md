## 项目上下文摘要（侧栏分组折叠菜单）

生成时间：2026-07-30 14:21:17 +08:00

### 1. 需求、范围与验收意图

- **目标**：优化控制台菜单栏，将平铺入口改为分组下拉折叠，提高查找效率并减少侧栏滚动。
- **范围**：控制台左侧主导航、导航常量、折叠交互、角色过滤和 760px 响应式行为。
- **不变项**：现有 18 个页面入口、当前页面高亮、管理员入口过滤规则、顶部页面标题和所有业务面板保持不变。
- **交互契约**：桌面一次展开一个业务组；当前页面所属组默认展开；组可手动收起；外部切换页面时自动展开对应组；手机端平铺全部可见入口。

### 2. 相似实现分析

- **实现 1**：`app/Console.tsx:1033`
  - 模式：侧栏直接读取 `nav`，根据角色过滤并渲染按钮，`tab` 是当前页面唯一状态。
  - 可复用：`tab`、`setTab`、管理员角色和现有按钮高亮协议。
  - 需注意：提醒、智能体、知识库等多个内部入口也会调用 `setTab`，菜单必须响应外部页面切换。
- **实现 2**：`app/features/constants.ts:51`
  - 模式：18 个入口集中定义为 `[Tab, icon, label]` 元组，页头标题与侧栏共同复用。
  - 可复用：现有 Tab、图标字符和中文标签，分组必须成为新的唯一事实来源并继续派生平铺 `nav`。
  - 需注意：普通用户只隐藏 `permissions`、`logs`、`users`，其他入口仍保留。
- **实现 3**：`app/Console.tsx:1049`
  - 模式：工作流启动器使用布尔状态、按钮文字和条件内容实现展开/收起。
  - 可复用：显式按钮、状态文本和简洁切换逻辑。
  - 需注意：主导航需要补充 `aria-expanded`、`aria-controls` 和 `aria-current`，保证键盘与辅助技术可用。
- **实现 4**：`app/Console.tsx:1063`
  - 模式：运行状态面板在当前组件内维护折叠状态，并用 `.collapsed` 控制表现。
  - 可复用：使用 React 状态作为交互事实来源，CSS 只负责显示效果。
- **实现 5**：`app/globals.css:5043` 与 `app/globals.css:5105`
  - 模式：980px 下缩窄侧栏，760px 下侧栏转为顶部横向导航。
  - 可复用：桌面分组、手机平铺的两级响应式策略。
  - 需注意：手机端不能因为桌面组处于收起状态而丢失入口。

### 3. 项目约定

- **命名约定**：React 模块使用 PascalCase，函数和 CSS 类使用 camelCase，测试文件使用 `*.test.mjs`。
- **文件组织**：共享导航数据位于 `app/features/constants.ts`，独立 UI 模块放入 `app/features/navigation/`，全局样式位于 `app/globals.css`。
- **导入顺序**：React 导入在前，动态模块与内部模块随后，类型使用 `import type`。
- **代码风格**：双引号、两空格缩进、UTF-8 无 BOM；中文用于界面文本、测试描述、注释和文档。

### 4. 深模块与接口

- **模块**：`SidebarNavigation`。
- **接口**：`activeTab`、`isAdmin`、`onSelect` 三个参数。
- **实现**：隐藏分组过滤、活动组定位、折叠状态、无障碍属性和导航按钮渲染。
- **深度**：`Console` 不需要了解组数据、管理员过滤或折叠规则，只负责提供页面状态和切换回调。
- **删除测试**：若删除该模块，分组、折叠、角色过滤和无障碍逻辑会重新散落回 `Console`，因此模块具备实际深度和局部性。

### 5. 菜单分组

- **核心工作**：智能助手、图文视频生成、沉淀中心。
- **知识与自动化**：企业知识、智能体中心、自动化工作流、数据采集。
- **企业运营**：企业架构、监控看板、合同中心、审批中心。
- **系统与接入**：模型接入、平台接入、权限中心、审计日志、账号管理。

### 8. 风险与边界条件

- **角色变化**：管理员专属入口只在管理员组数据中出现，普通用户不会看到空组。
- **外部跳转**：`activeTab` 变化时展开目标组，避免内容已切换但菜单仍藏在其他组。
- **手动收起**：活动组可收起；只要页面未变化，不会被 effect 立即强制打开。
- **手机端**：CSS 必须覆盖桌面收起状态，保证所有可见入口都能横向访问。
- **性能**：18 个静态入口和 5 个分组，状态更新为常量级，不引入网络或昂贵计算。
