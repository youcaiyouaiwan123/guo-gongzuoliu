### 1. 相似实现分析

- **基础导航规则**：`app/globals.css` 的 `nav button` 与响应式断点控制入口按钮字号。
- **分组标题规则**：同文件 `.sidebarNav .navGroupToggle` 原先在桌面和窄屏分别硬编码 10px、9px。

### 2. 项目约定

- 沿用全局 CSS 的 kebab-case 自定义属性、现有 980px/760px 断点和相邻规则组织方式。
- 不新增运行时状态、第三方依赖或组件接口。

### 3. 可复用组件清单

- `SidebarNavigation`：保持既有分组标题和入口结构不变。
- `.nav button`：保持导航按钮的交互和响应式行为。
- `.sidebarNav`：作为统一字号变量的作用域。

### 4. 测试策略

- 使用现有 `npm test`（构建及 Node 测试）、`npx tsc --noEmit` 和 `npm run lint`。
- 通过 CSS 断点规则确认分组标题与入口共同引用同一字号变量。

### 5. 依赖和集成点

- 唯一改动点为 `app/globals.css` 侧栏导航样式。
- 不影响 `Console.tsx`、导航数据、权限过滤、接口或持久化数据。

### 6. 关键风险点

- 桌面字号从原先较小的分组标题调整为与入口相同，需确认侧栏宽度下不发生文本溢出；现有标题均为短中文标签，构建和已有截图规则可覆盖该风险。
